How this differs from the detailed local Atlas tool: each hotspot here is checked as a single point (real OSM proximity to mapped water/substations/industrial land/telecom sites), not a dense 1km grid. Treat a match here as "worth a closer look," not a verified site — open the companion North America Data Center Atlas tool and load this exact area for the full dense-grid verification before doing anything with it.

Sources: OpenStreetMap / Overpass API (live, ODbL) for water/grid/land/connectivity. Policy check covers Texas and Illinois only (documented state programs) — every other state shows as policy-unknown, not policy-fail.

Not established by this tool: water rights, spare grid capacity, land ownership/zoning, actual fiber routes, and permitting specifics. 68 locations were hand-picked as known industrial, power, or fiber hub areas — this is not an exhaustive scan of the continent, and strong sites in less-obvious locations can be missed.
